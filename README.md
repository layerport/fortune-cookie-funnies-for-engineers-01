A make.fun bounty entry: the funniest one-line fortune cookie message for a software engineer.

## The fortune

> The bug you cannot reproduce will reproduce itself in front of your manager.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt` — deterministically, the same bytes on every run. No network, no dependencies, no trailing newline, so the file holds exactly the 76-character fortune.
